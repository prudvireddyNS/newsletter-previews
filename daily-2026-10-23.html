Google Cloud introduces Agent Compute Engine for sandboxed agents

Google says Agent Compute Engine gives every AI agent a hardware-isolated microVM with container-speed execution and no credentials inside the sandbox. This is infrastructure for agent “hands,” not model polish: useful if your agent needs filesystems, browsers, tools, and network access at scale.

NVIDIA is releasing a post-training framework that turns Cosmos 3 into streaming, action-conditioned world simulators. Modal open-sources Spindle, a Tinker-compatible training server

Modal’s Spindle is an open-source, Tinker-compatible training server that runs in your Modal workspace. The pitch is control and GPU-time pricing instead of token pricing; the practical win is keeping existing Tinker-style loops while changing the backend and model configs.

1Password launches credential delegation for AI agents

1Password for Agents gives users a way to approve agent logins without exposing passwords to the agent itself. This is the kind of plumbing agent apps need before they touch real accounts, though institutions still struggle to distinguish user-authorized agent activity from risk.

Canva releases Craft, its first in-house image generation model

Canva Craft is Canva’s first image model, built for design-heavy outputs rather than generic image generation. The interesting part is workflow integration: images can become layered Canva designs, and Canva plans API, MCP, and faster variants for broader distribution.

TechCrunchX

Replit adds an autonomous on-call agent for production apps

Replit Monitoring Agent extends monitoring from alerting into investigation, code changes, validation, and optional deployment. It is aimed at small teams and solo builders running apps on Replit; the big question is how much autonomy users will actually grant in production.

Replit Blog
08

Carbon-X applies mid- and post-training to DNA reasoning

Carbon-X is a 14.8B decoder-only model trained jointly on DNA sequences and natural language, with a released recipe. The strong claim is not just benchmark lift, but that domain mid-training can move an open model toward frontier bio performance without distillation.
